# Crown Clothing — E-Commerce Platform

Full-featured e-commerce application with Stripe payment integration.

## Tech Stack

- React
- Redux (state management)
- Firebase (authentication + database)
- Stripe (payment processing)
- Styled Components

## Features

- User authentication (sign up, sign in, sign out)
- Product catalog with categories
- Shopping cart with persistence
- Checkout flow with Stripe integration
- Order history
- Responsive design

## Setup

```bash
npm install
npm start
```

**Environment variables required:**
- Firebase config
- Stripe publishable key

Built to demonstrate full-stack e-commerce patterns and payment integration.
